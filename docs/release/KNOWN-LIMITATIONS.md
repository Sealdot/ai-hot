# Alpha 已知限制

- 验收只证明本地单用户的离线工程闭环。真实信源可用率、真实性、采集表现、模型质量、用户价值均未验证；信源目录的禁用原因是历史配置标签，未做在线复核。
- 依赖事先安装的 Node.js 24+（本机实际为 24.14.0），内建 node:sqlite 仍输出 ExperimentalWarning。离线源码包不含 Node 二进制；本机实测 macOS，Linux 离线流程结果见 Release 的 GitHub CI 记录；未实测 Windows、其他 Node 版本及长期运行。
- 推荐使用 `demo:offline` / `verify:offline`。其子进程清除继承凭证，只允许指定的本地 HTTP 端口；这是进程内网络守卫，不是操作系统断网证明。测试的应用时间固定，UUID、临时端口、目录名及数据库字节不要求逐字节一致。
- 普通 `npm start` 使用当前时间并读取可选 .env.local / 继承环境。完整内置目录初始全部停用，但显式启用或单源重试会访问该信源；删除 sources.json 会让启动合并恢复内置默认配置。要保证离线，请使用带守卫的演示命令。
- 单用户本地 API 不提供多用户账户隔离；本地监控/阅读写入基于同源检查，非浏览器本机进程可调用。管理员接口需本地自动生成令牌；不部署公网、不安装持久服务。
- 抓取、聚类、选入精选采用规则。简报原文摘录有来源 ID，但不等于事实已被独立证实；监控条件为现有实现的宽松匹配。3 条验收文章生成 3 条事件简报，其中只有 1 条达到精选门槛。
- 日报窗口为上海时区每日 08:05 向前 24 小时；没有模型时明确 degraded。已验证启动补跑和手工冻结，未等待真实 24 小时验证定时任务或跨日长期任务竞态。
- SQLite 备份覆盖文章、简报、阅读状态、监控器、日报及数据库内健康/任务记录；**不覆盖 sources.json、editorial-overrides.json、管理员令牌、.env.local 或服务配置**。这些文件需自行另备。阅读库 JSON 导出仍主要覆盖旧文章级状态，完整迁移应使用 SQLite 备份。
- 恢复操作必须先停止对应候选服务；脚本校验 SQLite 完整性和 AI HOT 核心表，拒绝符号链接及目录外文件，先备份当前库再原子替换。尚无跨进程服务锁、备份加密或自动灾备编排，不应对运行中的数据库恢复。
- 本轮不启动或恢复原工作区。源码快照与原 Git 历史可恢复源码；真实运行数据库没有另做一致性快照，仍保留原位置。
- 本项目以 MIT 发布，维护者已确认源码及保留样例的公开权利。源码与外部信源内容的权利分开；信源链接不表示可重新授权第三方文章。
