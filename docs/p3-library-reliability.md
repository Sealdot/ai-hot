# P3：本地资料库与可靠性

## 目标

让 AI HOT 的阅读资产可以安全迁移、清晰管理并定期复盘，同时让本机信源健康和每次 Git 同步后的质量状态更容易判断。所有用户数据继续保留在本机 SQLite；不新增账户、云同步或外部数据库。

## 范围与设计

### 1. 资料库与迁移

- 新增 `#/library`，展示收藏、笔记、活跃偏好与本地备份摘要。
- 导出支持 JSON（可导入的完整阅读快照和日报）与 Markdown（便于阅读或放入知识库）。
- 导入只接收已导出的 JSON；仅合并当前仍存在的文章，校验字段长度和枚举。阅读状态与反馈按更新时间合并，未知文章和较旧记录不会覆盖本地数据；日报随 JSON 导出供归档，整库恢复需使用 SQLite 备份。写入前自动建立 SQLite 备份。
- UI 显示最近备份，并提供明确的离线恢复命令。SQLite 整库恢复必须在服务停止后执行，避免在线覆盖数据库。

### 2. 偏好管理

- 资料库按主题和信源列出当前有效偏好及聚合强度。
- 用户可逐项撤销。撤销会移除这一目标的所有本机反馈记录，因此立刻停止对后续排序的影响。

### 3. 最近 7 天复盘

- 新增 `#/weekly`，提供最近 7 天已读、收藏、更新笔记和未读积压统计。
- 展示本周收藏、近期笔记和优先待读；待读仍以编辑优先级、时效和已启用偏好排序。

### 4. 信源健康与持续验证

- 信源透明页提供全部、健康、延迟、失败、等待筛选；“延迟”按 `max(3 × 抓取周期, 6 小时)` 从最近成功时间动态计算。
- GitHub Actions 在 push 和 pull request 时运行测试、Node 语法检查和 OpenAPI YAML 校验。

## 本地接口

| 接口 | 作用 | 保护 |
| --- | --- | --- |
| `GET /api/local/library` | 资料库摘要、偏好与备份清单 | 无跨域读取许可 |
| `GET /api/local/library/export?format=json|markdown` | 下载本机资料快照 | 无跨域读取许可 |
| `POST /api/local/library/import` | 校验并合并 JSON 快照；自动备份 | 同源写入 |
| `POST /api/local/library/backup` | 创建 SQLite 备份 | 同源写入 |
| `POST /api/local/preferences/clear` | 撤销一个主题或信源偏好 | 同源写入 |
| `GET /api/public/reader/weekly` | 最近 7 天复盘 | 本机公开阅读数据 |

## 用例与验收

| 用例 | 操作 | 预期结果 |
| --- | --- | --- |
| 导出迁移 | 下载 JSON 与 Markdown | JSON 含阅读状态、偏好和日报；Markdown 含可读的收藏、笔记和日报摘要 |
| 安全导入 | 上传此前导出的 JSON | 无效结构被拒绝；有效数据合并；导入前出现新备份；未知文章不会被写入 |
| 撤销偏好 | 在资料库点击某主题/信源的撤销 | 该目标从偏好清单消失，后续列表不再应用其排序分 |
| 周末复盘 | 打开“本周” | 看到最近 7 天阅读、收藏、笔记、未读统计及对应文章 |
| 信源排障 | 在信源页选择“延迟”或“失败” | 仅显示对应状态，并保留最近成功时间与失败信息 |
| 提交守门 | push 或 PR | CI 自动运行单元测试、语法检查和 OpenAPI 解析 |

## 验证策略

- SQLite：导出/导入合并、导入校验、偏好撤销、自动备份。
- API 冒烟：两种导出格式、导入、备份、每周复盘、信源筛选数据。
- UI：资料库撤销偏好、导出链接、本周摘要、信源状态筛选。
- 回归：`npm test`、`node --check`、OpenAPI YAML、`git diff --check`；CI 文件结构检查。
